# Remotion: анимационная инфографика

`docs/PROJECT_CONTEXT.md` §5 требует анимационной инфографики. Remotion рендерит видео из React-кода: плашки с цифрами, титры, переходы. Он **не** генерирует видео — картинку сцены рисует flux, перебивку собирает ffmpeg, аватара снимает Replicate.

## Лицензия

Проверено 14.08.2026: для физлиц, некоммерческих организаций и компаний до трёх сотрудников включительно Remotion бесплатен, в том числе для коммерческого использования. С четырёх сотрудников нужна платная лицензия: тариф Automators — $0.01 за рендер при минимуме $100 в месяц (наш случай при автоматическом конвейере), Creators — $25 за место в месяц, Enterprise — от $500.

Наша команда попадает под бесплатную лицензию.

## Что уже сделано

- **План наложения** — `server/utils/remotion/overlay-plan.ts`. Из сцен ролика выбираются те, где в тексте есть цифра с единицей измерения (процент, кратность, рубли, минуты), и на них планируется плашка. Таймкоды считаются от начала ролика.
- **Адаптер рендера** — `server/utils/remotion/render.ts`. Пакеты грузятся динамически, отсутствие любого из них даёт `skipped` с причиной, а не падение.
- **Подключение к сборке** — шаг `assembly` накладывает графику после того, как ролик собран. Отказ слоя ролик не портит: файл уже готов к публикации.

Правила плана:

- на сцену ведущей плашка не ставится — там работают лицо и речь, и графика забирает внимание;
- плашка появляется через секунду после начала сцены и уходит за полсекунды до склейки;
- сцены короче трёх секунд пропускаются;
- не больше пяти плашек на ролик, иначе получается презентация.

## Композиции

Лежат в `remotion/`:

- `index.ts` — точка входа, её ищет адаптер;
- `Root.tsx` — две композиции, `VerticalOverlays` (1080×1920) и `HorizontalOverlays` (1920×1080); длительность считается из `durationSec` в пропсах, иначе лишние кадры дорисовали бы чёрный хвост;
- `Overlays.tsx` — сам слой: готовый ролик через `OffthreadVideo` плюс плашки поверх.

Плашка держится в верхней трети — низ кадра занят субтитрами. Появляется пружиной примерно за треть секунды и уходит затуханием: резкий скачок читается как ошибка рендера, а не как акцент. Число выделяется крупно, пояснение идёт подписью.

Композиции — React и JSX, а остальной проект на Vue, поэтому у них свой `remotion/tsconfig.json`. Проверка типов:

```bash
bunx tsc --noEmit -p remotion/tsconfig.json
```

Проверка сборки без браузера и без рендера кадров:

```bash
bun run scripts/check-remotion-bundle.ts
```

На 14.08.2026 сборка занимает около 13 секунд.

## Чего не хватает для запуска

1. **Headless Chrome не скачан.** При первом рендере Remotion потянет его сам — порядка 150 МБ и заметное время. На стенде это отразится на первом прогоне и на размере кеша.
2. **Рендер не проверялся на готовом ролике.** Бандл собирается, типы чисты, но сколько времени занимает наложение на ролик 70–90 секунд — неизвестно, пока не будет первого файла.

Слой включён по умолчанию и выключается явным `REMOTION_ENABLED=false`. Отсутствие пакетов, композиций или самих плашек в ролике даёт мягкий отказ с причиной в логе шага — ролик собирается в любом случае.

Порядок проверки: собрать один ролик → замерить время наложения → решить, идёт ли слой в партию на 300 роликов.
