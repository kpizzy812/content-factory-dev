# Регламент: как запостить видео (YouTube, browser-automation)

Документированный путь оператора + что происходит автоматически. Скриншоты каждого шага — в `screens/post-guide-*.png`.

---

## Предусловия (проверить один раз перед серией постов)
- Залогинен в ZavodCamp (Saturn).
- Аккаунт с методом **browser_automation**: привязан Indigo-профиль + прокси (статус **healthy**).
- В Indigo-профиле **залогинен YouTube**, cookies сняты в snapshot. (Проверяется в Шаге 3 по бейджу «Залогинен». Если нет — см. Приложение А.)

---

## Шаги (каждое нажатие)

**Шаг 1.** Открыть **`/posting-jobs`** → нажать **«Создать задачу»** (вверху справа). `screens/post-guide-01-queue.png`

**Шаг 2.** Открылась модалка «Создать задачу постинга». `screens/post-guide-02-modal-empty.png`

**Шаг 3.** В поле **Аккаунт** выбрать нужный аккаунт. Появятся бейджи готовности — должно быть:
`Здоров` ✅ · **`Залогинен`** ✅ · **`Готовность 4/4`** ✅.
Если **`Не залогинен`** / Готовность < 4/4 → Приложение А. `screens/post-guide-03-account-selected.png`

**Шаг 4.** В поле **Видео** выбрать видео (статус completed). Заголовок / описание / хэштеги **автозаполнятся** из видео. `screens/post-guide-04-video-selected.png`
- ⚠️ **«Caption не утверждён»** — это **мягкое предупреждение**, кнопку **не блокирует** (постинг возьмёт заголовок из формы). Опционально утвердить через «Открыть редактор» → /videos/:id.

**Шаг 5.** Выбрать **Видимость** (Приватно / По ссылке / Публично) и **Made for kids** (обычно **«Не для детей»**). `screens/post-guide-05-ready.png`

**Шаг 6.** Проверить панель **«Готовность к публикации»** — 5 пунктов: Видео · Прокси · Indigo · Вход в YouTube · Caption.

**Шаг 7.** Нажать **«Создать задачу»**. Кнопка активна, когда: выбран аккаунт+видео, заполнен заголовок, выбраны видимость и аудитория, логин подтверждён. `screens/post-guide-06-job-created.png`

**Шаг 8.** Задача появилась в очереди со статусом **`queued`**. Воркер подхватит её **через ~30 секунд**. Дальше — автоматически.

---

## Что происходит дальше (автоматически, мониторинг)

Статусы: `queued` → `preparing` → `uploading` → … → `published` / `failed`.
Фазы внутри (видно в логах джобы): `login_check` → `navigate_upload` → `file_upload` (attach) → `fill_details` → `set_visibility` → `publish` → `verify`.

**Где смотреть:** карточка джобы в очереди (статус), кнопка **«Логи»**, уведомления bell-bot в Telegram.

**Исходы:**
| Статус | Что значит | Действие оператора |
|---|---|---|
| **published** ✅ | Опубликовано, есть share-URL | Готово |
| **failed: browser_lost / attach_not_confirmed** | Indigo нестабилен на тяжёлом шаге заливки | Авто-retry (до 5× за 90 мин). Это инфра (CPU), НЕ действие оператора. Профиль чистится сам |
| **failed: requires_human** | Publish кликнут, verify не подтвердил | Проверить видео на канале вручную (опубликовано/черновик) |
| **failed: login_required** | Аккаунт реально разлогинен | Приложение А |

## Приложение А — если «Не залогинен» / login_required
1. Открыть Indigo-профиль в **Indigo X desktop**.
2. Зайти на **youtube.com/studio**, убедиться что залогинен (войти в Google-аккаунт, если нет; пройти challenge если просит).
3. **Пере-снять cookies** в ZC (export / snapshot на странице профиля).
4. Вернуться в модалку → **«Запустить login-check»** → должно стать **«Залогинен»**.

---

## Важные правила (автономия сервиса)
- **Один browser_automation постинг идёт за раз** (автоматическая сериализация). Несколько задач — ждут очереди по одной. Это снижает нагрузку на машину Indigo.
- **Профиль чистится и готовится автоматически** на старте каждой задачи (закрываются лишние вкладки). **Вручную поднимать профиль НЕ нужно.**
- На время прогона желательно **закрыть фоновые программы** на машине Indigo и **не гонять несколько профилей** — это снижает CPU (главный лимит).
