# Контент-Завод — Спецификация проекта

> ТЗ v1.1 · Март 2026 · Обязательный документ для разработки

Контент-Завод — автоматизированная система на базе AI-агентов, которая без участия человека находит трендовые видео, генерирует сценарии, создаёт креативы и загружает их в соцсети (TikTok, Instagram, YouTube). Система работает под конкретное приложение и пачку аккаунтов, привязанных к нему.

**Контекст:** проект реализуется с нуля — backend, frontend и интеграции с платформой MarketingCamp.

**Целевой пользователь:** маркетолог, который разбирается в маркетинге, но не в технологиях. Интерфейс платформы должен предоставлять No-Code опыт — визуальное построение конвейера из модулей, аналогично сервисам автоматизации (N8N, Make), но встроенное в платформу. Никакого кода, терминалов или технических настроек для оператора.

---

## Архитектура: 5 модулей

Завод — конвейер из 5 последовательных модулей. Каждый модуль — отдельный агент или цепочка агентов. Данные между модулями передаются через общую базу.

```
[Trendwatcher] → [Генератор сценариев] → [Генерация видео] → [Загрузка в соцсети] → [Аналитика]
      ↑                                                                                    |
      └────────────────────── обратная связь (Phase 2) ────────────────────────────────────┘
```

---

## Модуль 1 — Trendwatcher (поиск трендов)

Агент мониторит TikTok, Instagram, YouTube по заданным тегам и ключевым словам. Находит вирусные ролики, анализирует через AI и сохраняет бриф в базу.

| Аспект | Детали |
|--------|--------|
| Источники | TikTok API (Apify), Instagram, YouTube |
| Фильтрация | Теги, гео, язык, лимиты просмотров |
| AI-анализ | Хук, структура сцен, визуальный стиль, почему залетело |
| Выход | Бриф в базу креативов |
| Запуск | По расписанию (настраивается в интерфейсе) |

---

## Модуль 2 — Генератор сценариев

На основе брифа из базы агент генерирует сценарий под конкретное приложение.

- Берёт бриф из базы → адаптирует под выбранное приложение
- Генерирует **3 варианта** сценария на выбор
- Структура: **хук** (первые 3 сек) → **основная часть** → **CTA**
- Прописывает визуальный стиль для ролика (цвета, атмосфера, персонаж)
- Сохраняет выбранный сценарий в базу для Модуля 3

---

## Модуль 3 — Генерация видео

Агент берёт сценарий, генерирует изображения/видеофрагменты, собирает итоговый ролик.

- Генерация изображений по промпту (визуальный стиль из сценария)
- Сборка видеофрагментов в единый ролик
- Наложение текста, субтитров, музыки
- **Выход:** готовый видеофайл (9:16 для TikTok/Reels, 16:9 для YouTube)

---

## Модуль 4 — Загрузка в соцсети

Агент берёт готовый ролик и загружает в указанные аккаунты, привязанные к приложению.

- Платформы: **TikTok**, **Instagram Reels**, **YouTube Shorts**
- Загрузка через API каждой платформы
- Привязка аккаунта к приложению — загружаем только в нужные аккаунты
- Автопостинг по расписанию или немедленно
- Статус загрузки сохраняется в базу

---

## Модуль 5 — Аналитика и обратная связь (Phase 2)

> Реализуется во вторую очередь, после стабилизации модулей 1–4.

- Сбор метрик: просмотры, досматриваемость, лайки, CTR
- AI-анализ: почему залетело / не залетело
- Успешные ролики → отдельная база референсов
- Данные передаются в Trendwatcher — система учится на своих результатах

## Управление приложениями и аккаунтами

Завод поддерживает работу с несколькими приложениями. Оператор выбирает приложение — завод работает только с привязанными аккаунтами.

### Сущности

| Сущность | Поля | Описание |
|----------|------|----------|
| Приложение | Название, описание, ключевые слова, гео, язык | Базовые настройки для генерации контента |
| Аккаунт | Платформа, логин, статус, приложение | Аккаунт в соцсети, привязанный к приложению |
| Пачка аккаунтов | Список аккаунтов, приложение, статус | Группа аккаунтов для массовой загрузки |

### Правила
- Один аккаунт привязан только к одному приложению
- Можно добавлять, удалять, переключать аккаунты в интерфейсе

---

## Дашборд аналитики по креативам

Единый дашборд для просмотра статистики по всем загруженным роликам со всех аккаунтов. Данные через API платформ.

### Режимы просмотра
- **Сводный вид** — все аккаунты всех платформ, агрегированные метрики
- **Вид по аккаунту** — статистика одного конкретного аккаунта
- **Фильтры:** по приложению, платформе, периоду, аккаунту

### Метрики по каждому ролику

| Метрика | Описание | Платформы |
|---------|----------|-----------|
| Просмотры | Общее число просмотров | TikTok, Instagram, YouTube |
| Досматриваемость | % досмотревших до конца / средний % просмотра | TikTok, Instagram, YouTube |
| Лайки | Количество лайков | TikTok, Instagram, YouTube |
| Комментарии | Количество комментариев | TikTok, Instagram, YouTube |
| Шеры / репосты | Количество шеров и репостов | TikTok, Instagram, YouTube |
| CTR по ссылке | Клики по ссылке в описании / профиле | TikTok, Instagram, YouTube |
| Прирост подписчиков | Новые подписчики с момента публикации | TikTok, Instagram, YouTube |

### Сводные показатели (топ карточки)
- Лучший ролик за период (по просмотрам и досматриваемости)
- Общий прирост подписчиков по всем аккаунтам за период
- Средняя досматриваемость по всем роликам
- Топ-5 роликов по CTR

### Таблица роликов
Полная таблица всех загруженных роликов с сортировкой по любой метрике:
- Превью / миниатюра
- Аккаунт и платформа
- Дата публикации
- Все метрики
- Ссылка на оригинальный ролик
- Статус: активен / удалён / заблокирован

### Источники данных
Данные через официальные API по расписанию (раз в час или раз в день):
- **TikTok** — TikTok Business API
- **Instagram** — Instagram Graph API (через Meta Business)
- **YouTube** — YouTube Data API v3

> API платформ могут возвращать данные с задержкой (Instagram — до 24 часов). Отображаем время последнего обновления рядом с метриками.

## Интерфейс администратора

Оператор запускает циклы, следит за статусом, вносит правки. No-Code интерфейс — визуальное управление конвейером без доступа к коду или технических знаний.

### Дашборд завода
- Текущий статус завода (работает / стоит / ошибка)
- Последние запущенные циклы и их статус
- Количество роликов за день/неделю
- Уведомления об ошибках

### Управление приложениями
- Список приложений
- Привязка аккаунтов к приложению
- Настройка тегов, гео, языка для каждого приложения

### Запуск цикла
- Выбор приложения и пачки аккаунтов
- Кнопка запуска / остановки
- Ручной запуск или по расписанию

### База креативов
- Просмотр всех найденных трендов и брифов
- Просмотр сгенерированных сценариев
- Просмотр готовых роликов перед загрузкой
- Возможность одобрить / отклонить ролик вручную перед постингом (опционально)

### База идей (ручной ввод)
- Оператор вручную закидывает ссылку на ролик
- Система делает транскрибацию, анализирует структуру, сохраняет как идею
- Идея попадает в очередь для Модуля 2

### Логи и мониторинг
- Лог всех действий агентов
- Ошибки с описанием и статусом (решена / не решена)
- Telegram-уведомления при критических ошибках

## Telegram-бот

### Мониторинг и алерты
- Уведомление при запуске цикла и успешной загрузке ролика
- Алерт при критической ошибке (после 2–3 неудачных попыток агента)
- Команды: `/status`, `/stop`, `/start`

### Анализ чужих роликов
- Ссылка → транскрибация на нужном языке (RU, EN, DE и др.)
- Разбор структуры: хук, основная часть, CTA, визуальный стиль
- Объясняет почему залетело
- Сохраняет как идею в базу → передаёт в Модуль 2

## Интеграция с MarketingCamp

| Направление | Данные |
|-------------|--------|
| MarketingCamp → Завод | Данные Trendwatcher (тренды, брифы) |
| Завод → MarketingCamp | Статус загрузок, метрики роликов |

- Единый API-коннект: общий ключ, обмен запросами
- Завод видит те же приложения и аккаунты, что и платформа
