# ContentFactory

ContentFactory - универсальная платформа для автономного производства, проверки, публикации и аналитики вертикального AI-контента.

Проект развивается на основе VideoCamp, но не привязан к одному клиенту или внешней системе. Интеграции с источниками трендов, мессенджерами, CRM и социальными сетями подключаются через адаптеры.

## Основные возможности

- поиск и анализ трендов;
- генерация гипотез, воронок, лид-магнитов и сценариев;
- библиотека исходников ведущих;
- Replicate для lip-sync и генерации медиа;
- гибридный монтаж FFmpeg и Remotion;
- автоматический QA;
- официальная публикация в социальные сети;
- сквозной tracking token и аналитика конверсий;
- очереди и воркеры с целевой мощностью до 300 роликов в день.

## Стек

- Nuxt 4 и Vue 3;
- Bun;
- PostgreSQL и Prisma;
- Replicate;
- FFmpeg;
- Remotion;
- объектное хранилище.

## Локальный запуск

```bash
bun install
cp .env.example .env
bunx prisma migrate dev
bun run dev
```

Не добавляйте реальные токены в `.env.example` или Git.

Для локальной разработки без платных запросов выставьте `REPLICATE_MOCK_MODE=true`. В рабочем окружении Replicate запускается асинхронно, результаты сразу копируются в постоянное хранилище, а потерянные webhook подхватываются recovery-поллингом.
